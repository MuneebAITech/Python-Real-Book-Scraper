\# Real Book Scraper with Pagination



A Python web scraping project that extracts book information from BooksToScrape and exports the data to CSV and Excel files.



\## Features



\* Scrapes book data from multiple pages

\* Handles pagination automatically

\* Collects 1000 books from 50 pages

\* Exports data to CSV

\* Exports data to Excel

\* Logs scraping activity

\* Logs request and runtime errors

\* Includes timeout and exception handling



\## Technologies Used



\* Python

\* Requests

\* BeautifulSoup4

\* Pandas

\* OpenPyXL
